## Fix 15: Deduplicate and Curate Field Updates
**Severity: MEDIUM | Effort: 1 hour | Page: Project Detail**

The TOVP project page has 6+ nearly identical AI-generated updates from March 26–29, 2026.

```tsx
// Deduplicate by checking content similarity before displaying
const deduplicatedUpdates = updates.reduce((acc, update) => {
  const isDuplicate = acc.some(existing => {
    const similarity = calculateSimilarity(existing.content, update.content);
    return similarity > 0.7; // 70% similar = duplicate
  });
  if (!isDuplicate) acc.push(update);
  return acc;
}, []);

// Limit display to 1 update per week per project
const weeklyUpdates = deduplicatedUpdates.filter((update, index) => {
  if (index === 0) return true;
  const prevDate = new Date(deduplicatedUpdates[index - 1].date);
  const currDate = new Date(update.date);
  return (prevDate - currDate) > 7 * 24 * 60 * 60 * 1000; // 7 days
});
```

## Fix 20: Add Currency Toggle for International Donors
**Severity: LOW | Effort: 1.5 hours | Page: Homepage / Seva Section**

Seva tiers show ₹ with approximate USD but no toggle for GBP, AUD, KES (the target donor regions).

```tsx
const EXCHANGE_RATES = {
  INR: 1, USD: 0.012, GBP: 0.0095, AUD: 0.019, KES: 1.55
};
const CURRENCY_SYMBOLS = { INR: "₹", USD: "$", GBP: "£", AUD: "A$", KES: "KSh" };

const [currency, setCurrency] = useState(() => {
  // Auto-detect from locale
  const locale = navigator.language;
  if (locale.startsWith('en-US')) return 'USD';
  if (locale.startsWith('en-GB')) return 'GBP';
  if (locale.startsWith('en-AU')) return 'AUD';
  return 'INR';
});

function formatAmount(inrAmount: number): string {
  const converted = inrAmount * EXCHANGE_RATES[currency];
  return `${CURRENCY_SYMBOLS[currency]}${converted.toLocaleString(undefined, { maximumFractionDigits: 0 })}`;
}

// Currency selector at top of seva section:
<div className="flex gap-2 mb-4">
  {Object.keys(CURRENCY_SYMBOLS).map(cur => (
    <button
      key={cur}
      onClick={() => setCurrency(cur)}
      className={`px-3 py-1 rounded text-sm ${currency === cur ? 'bg-primary text-white' : 'bg-muted'}`}
    >
      {CURRENCY_SYMBOLS[cur]} {cur}
    </button>
  ))}
</div>

// Tier cards:
<SevaCard title="Brick Donor" amount={formatAmount(1000)} />
```

**Verify:** Toggle currencies — amounts should update instantly in the user's selected currency.
